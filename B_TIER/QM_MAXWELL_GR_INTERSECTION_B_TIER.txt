1. QUANTUM PROJECTIVE ORBIT
---------------------------

Assume chi is not a scalar multiple of e_0. After a constant phase choice,
write

  chi = c_0 e_0 + s_0 xi,

where

  c_0 = <e_0,chi> in (0,1),
  s_0 = sqrt(1-c_0^2),
  <e_0,xi> = 0,
  ||xi||_2 = 1.

Define

  O_chi := P(span_C{e_0,xi}) isomorphic to CP^1.

A normalized chart is

  psi(theta,phi)
    = cos(theta/2)e_0
      + exp(i phi) sin(theta/2)xi.

Define

  omega_FS := (1/2) sin(theta) dtheta wedge dphi,

so that

  integral_{O_chi} omega_FS = 2 pi.

Define the Schrödinger action one-form

  Theta_QM := hbar Im <psi,dpsi>.

THEOREM QMGI_QUANTUM_ACTION_ORBIT.

  d Theta_QM = hbar omega_FS.

DERIVATION.

Orthogonality gives

  <psi,dpsi> = i sin^2(theta/2)dphi.

Therefore

  Theta_QM = hbar sin^2(theta/2)dphi

and

  dTheta_QM
    = (hbar/2)sin(theta)dtheta wedge dphi
    = hbar omega_FS.

Hence the quantum action cell is

  A_Q := (1/(2pi)) integral_{O_chi} dTheta_QM = hbar.

2. STATIONARY QUANTUM PROFILE
-----------------------------

Define the neutralized charge density

  rho_chi := q(chi^2-1).

Since ||chi||_2=1 and |T^3|=1,

  integral_{T^3} rho_chi = 0.

Let Phi_chi be the unique zero-mean periodic solution of

  -epsilon0 Delta Phi_chi = rho_chi.

Define

  E_chi := -grad Phi_chi.

For an arbitrary real lambda define

  W_chi
    := lambda
       + (hbar^2/(2m))(Delta chi)/chi
       - q Phi_chi.

Then

  psi_chi(t,x) := exp(-i lambda t/hbar)chi(x)

satisfies

  i hbar partial_t psi_chi
    = [-(hbar^2/(2m))Delta + W_chi + q Phi_chi]psi_chi.

Because chi is real,

  J_chi
    := (q/m) Re(conj(psi_chi)(-i hbar grad)psi_chi)
    = 0.

Thus

  partial_t |psi_chi|^2 = 0,
  partial_t rho_chi = 0.

3. NUMBER-PRESERVING CHARGE OPERATOR
------------------------------------

On fermionic Fock space define

  C_chi := a^dagger(chi)a(e_0).

On the one-particle sector,

  C_chi = |chi><e_0|,
  C_chi^dagger = |e_0><chi|,

and therefore

  [C_chi,C_chi^dagger]
    = P_chi-P_0.

The diagonal of the integral kernel is

  diag(P_chi-P_0)(x)
    = chi(x)^2-1.

Hence

  rho_chi(x)
    = q diag([C_chi,C_chi^dagger])(x).

Moreover

  [N_hat,C_chi] = 0.

THEOREM QMGI_QM_TO_CHARGE.

The stationary quantum ray Gamma_chi=P_chi determines the stationary
neutralized charge rho_chi through a number-preserving profile-transfer
defect operator.

THEOREM QMGI_QM_TO_MAXWELL.

The encoded fields satisfy the stationary Maxwell equations

  div E_chi = rho_chi/epsilon0,
  div B_chi = 0,
  curl E_chi = 0,
  curl B_chi = 0,
  partial_t E_chi = 0,
  partial_t B_chi = 0.

DERIVATION.

Gauss law is the defining Poisson equation. The remaining identities follow
from E_chi=-grad Phi_chi and B_chi=J_chi=0.

Therefore the Gaussian kernel convention is exactly

  a_* = epsilon,
  l_* = epsilon/2,
  tau_epsilon = l_*^2.

10. UNIVERSALITY AND NONSELECTION
---------------------------------

THEOREM QMGI_ORBIT_UNIVERSALITY_GATE.

Suppose a single epsilon>0 matches a family of profiles chi and the pullback
coefficient is kappa(chi)>0. Then kappa(chi) is constant across that family.

DERIVATION.

Matching gives

  epsilon^2 = l_P^2/kappa(chi).

The left side is fixed, so the right-side coefficient is fixed.

STATUS = EXACT_B_TIER.


THEOREM QMGI_COEFFICIENT_NONSELECTION.

If kappa is unspecified, the matching equation cannot select epsilon. Indeed,
for every epsilon>0,

  kappa_epsilon := l_P^2/epsilon^2

satisfies

  kappa_epsilon c^3 epsilon^2/G = hbar.

STATUS = EXACT_B_TIER.

Thus the physical content is the independent GR computation of kappa, not the
subsequent scalar matching.
