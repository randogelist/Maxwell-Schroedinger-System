1. VACUUM ADM CONSTRAINTS
-------------------------

For a Riemannian metric g_ij and second fundamental form K_ij on Sigma, define

  tr_g K := g^{ij}K_ij,

  |K|_g^2 := g^{ik}g^{jl}K_ij K_kl.

The vacuum constraints are

  H(g,K)
    := R(g) + (tr_g K)^2 - |K|_g^2
     = 0,

  M_i(g,K)
    := nabla^j K_ij - partial_i(tr_g K)
     = 0.

These equations are the only GR equations used in the exact construction
below.


2. A CIRCULAR TRANSVERSE MAXWELL MODE
-------------------------------------

Fix

  n in Z, n != 0,
  k := 2 pi n,
  s>0,
  alpha in R/(2 pi Z).

Define

  a_{s,alpha,n}(x)
    := s ( cos(k z + alpha),
           sin(k z + alpha),
           0 ).

THEOREM CIRCULAR_MAXWELL_MODE.

The field a_{s,alpha,n} satisfies

  div a_{s,alpha,n} = 0,
  mean(a_{s,alpha,n}) = 0,
  Delta a_{s,alpha,n} = -k^2 a_{s,alpha,n},
  |a_{s,alpha,n}(x)| = s

for every x.

DERIVATION.

The field depends only on z and has zero third component, so its divergence
vanishes.  Nonzero Fourier frequency gives zero mean.  Two z derivatives give
-k^2, and cos^2+sin^2=1 gives constant pointwise norm.

STATUS = EXACT_B_TIER.


THEOREM CIRCULAR_HEAT_REGULARIZATION.

For epsilon>0,

  a_{epsilon;s,alpha,n}
    := exp((epsilon^2/4)Delta) a_{s,alpha,n}

has the explicit form

  a_{epsilon;s,alpha,n}
    = s_epsilon
      ( cos(k z + alpha),
        sin(k z + alpha),
        0 ),

where

  s_epsilon
    := s exp(-epsilon^2 k^2/4).

Consequently

  |a_{epsilon;s,alpha,n}(x)| = s_epsilon

is constant.

STATUS = EXACT_B_TIER.

This is the same Gaussian convention used by the Planck-kernel chain:

  multiplier = exp(-epsilon^2 |xi|^2/4).


3. VECTOR-TO-TT LIFT
--------------------

For every vector field a=(a1,a2,0) depending only on z, define the symmetric
2-tensor TT(a) by

  TT(a)_ij
    := (1/sqrt(2))
       [ [ a1,  a2, 0 ],
         [ a2, -a1, 0 ],
         [  0,   0, 0 ] ].

THEOREM FIXED_AXIS_VECTOR_TO_TT.

For every such a,

  trace_delta TT(a) = 0,
  partial^j TT(a)_ij = 0,
  |TT(a)|_delta^2 = |a|^2.

DERIVATION.

The diagonal entries cancel.  All tensor entries with a z index vanish, while
the remaining entries depend only on z, so the divergence is zero.  Direct
Frobenius contraction gives

  (1/2)(a1^2+a2^2+a2^2+a1^2)
    = a1^2+a2^2.

STATUS = EXACT_B_TIER.

Define

  sigma_epsilon
    := TT(a_{epsilon;s,alpha,n}).

Then

  sigma_epsilon is TT,
  |sigma_epsilon|_delta = s_epsilon

pointwise on T^3.


4. EXACT NONLINEAR VACUUM INITIAL DATA
--------------------------------------

Define two signs

  eta in {+1,-1}

and set

  g_epsilon := delta,

  K_epsilon^eta
    := sigma_epsilon
       + eta (s_epsilon/sqrt(6)) delta.

THEOREM CIRCULAR_TT_EXACT_VACUUM_DATA.

For every epsilon>0, s>0, n!=0, alpha, and eta in {+1,-1},

  H(g_epsilon,K_epsilon^eta)=0,
  M(g_epsilon,K_epsilon^eta)=0.

Hence

  (T^3,g_epsilon,K_epsilon^eta)

is exact smooth vacuum Einstein initial data.

DERIVATION.

Because g_epsilon=delta,

  R(g_epsilon)=0.

The TT property gives

  tr_delta sigma_epsilon = 0,
  div_delta sigma_epsilon = 0.

The trace is constant:

  tr_delta K_epsilon^eta
    = eta 3 s_epsilon/sqrt(6)
    = eta sqrt(3/2) s_epsilon.

Orthogonality of trace and tracefree parts gives

  |K_epsilon^eta|_delta^2
    = |sigma_epsilon|^2
      + |eta(s_epsilon/sqrt(6))delta|^2

    = s_epsilon^2
      + 3 s_epsilon^2/6

    = (3/2)s_epsilon^2.

Also

  (tr_delta K_epsilon^eta)^2
    = (3/2)s_epsilon^2.

Therefore H=0 pointwise.  The momentum constraint vanishes because
sigma_epsilon is divergence-free and the trace term is spatially constant.

STATUS = EXACT_B_TIER.


COROLLARY EXACT_MEAN_CURVATURE_BACKREACTION.

The exact mean curvature is

  tau_epsilon^eta
    := tr K_epsilon^eta
     = eta sqrt(3/2)
       s exp(-epsilon^2 k^2/4).

Thus the nonlinear GR trace mode is not optional in this exact flat-metric
family.  It is fixed by the transverse amplitude.

5. RELATION TO FLAT-TORUS LINEARIZATION STABILITY
-------------------------------------------------

Introduce an amplitude parameter r>=0 and a unit-norm circular TT tensor
sigma_hat with

  |sigma_hat|=1.

Define

  g_r := delta,

  K_r^eta
    := r sigma_hat
       + eta (r/sqrt(6))delta.

Then every r gives exact vacuum constraint data and

  (g_r,K_r^eta) -> (delta,0)

as r->0.

The tangent at r=0 is

  dot g = 0,
  dot K = sigma_hat + eta delta/sqrt(6).

THEOREM TRACE_MODE_RESOLVES_ENERGY_OBSTRUCTION.

The nonzero homogeneous trace component eta delta/sqrt(6) exactly balances the
positive TT quadratic contribution in the Hamiltonian constraint.

If the trace component is deleted while the flat metric is held fixed, the
second-order integrated Hamiltonian constraint has the positive form

  integral_T3
    [ |p_TT|^2
      + (1/4)|partial gamma_TT|^2 ] dx
    = 0,

under the standard flat-torus ADM perturbation convention.  It therefore
forces

  p_TT=0,
  partial gamma_TT=0.

For mean-zero TT perturbations this implies triviality.

6. CMC CONFORMAL FORMULATION
----------------------------

Let sigma be a smooth TT tensor on the flat torus and let tau be a nonzero
constant.  For a positive scalar phi define

  g_bar := phi^4 delta,

  K_bar
    := phi^(-2) sigma
       + (tau/3) g_bar.

The vacuum constraints reduce to the Lichnerowicz equation

  Delta phi
    = -(1/8)|sigma|^2 phi^(-7)
      + (1/12)tau^2 phi^5.

THEOREM CONSTANT_NORM_CMC_COMPLETION.

If

  |sigma|_delta = s0 > 0

is constant and tau!=0, then the positive constant

  phi
    = [ 3 s0^2/(2 tau^2) ]^(1/12)

solves the Lichnerowicz equation.  The reconstructed pair

  (g_bar,K_bar)

therefore satisfies the exact vacuum constraints.

DERIVATION.

For constant phi, Delta phi=0.  The equation reduces to

  -(1/8)s0^2 phi^(-7)
  + (1/12)tau^2 phi^5
  = 0,

which is equivalent to

  phi^12 = 3s0^2/(2tau^2).

STATUS = EXACT_B_TIER.

The explicit data of Section 4 are the normalized subcase

  phi=1,
  tau^2=(3/2)s0^2.


THEOREM YAMABE_ZERO_CMC_SIGN_GATE.

On the flat torus:

  (a) if sigma is not identically zero and tau=0, no positive solution of the
      Lichnerowicz equation exists;

  (b) if sigma=0 and tau!=0, no positive solution exists.

DERIVATION.

Integrate the Lichnerowicz equation over T^3.  The integral of Delta phi is
zero.  In case (a) the remaining right-hand side is strictly negative; in case
(b) it is strictly positive.

STATUS = EXACT_B_TIER.

GENERAL CMC SOURCE ENDPOINT.

For Yamabe-zero compact three-manifolds, nonzero TT seed sigma and nonzero

7. GAUGE AND ORBIT AUDIT

The phase alpha in

  a_{s,alpha,n}(z)

THEOREM CIRCULAR_PHASE_IS_TRANSLATION.

Changing alpha is generated by a spatial translation of T^3.  Therefore the
alpha-circle is gauge-equivalent after quotienting by the connected torus
