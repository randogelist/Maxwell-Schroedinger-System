This document continues the exact transverse Maxwell-to-GR chain through the
T2/Gowdy symmetry sector. It proves directly that the expanding circular CMC
vacuum data are smooth, T2-symmetric, twist-free, future-expanding, and
unpolarized. Standard Gowdy evolution theory then supplies a global future
areal development and future timelike geodesic completeness.

The resulting completeness statement is stronger than local existence, but is
not identical to nonlinear orbital stability. A separate high-frequency audit
isolates the oscillatory/corrector-stress gate.


0. FROZEN DATA
--------------

Coordinates on the unit three-torus:

  (x,y,z) in T3.

T2 generators:

  X := partial_x,
  Y := partial_y.

Let

  epsilon > 0,
  s > 0,
  n in Z with n != 0,
  k := 2 pi n,
  theta(z) := k z + alpha.

Define the smoothed circular transverse amplitude

  s_epsilon := s exp(-epsilon^2 k^2/4),

and the transverse vector field

  a_epsilon(z)
    := s_epsilon (cos theta(z), sin theta(z), 0).

Define the TT lift

  sigma_epsilon
    := (1/sqrt(2))
       [ [ a_1,  a_2, 0 ],
         [ a_2, -a_1, 0 ],
         [   0,    0, 0 ] ].

Then

  tr_delta sigma_epsilon = 0,
  div_delta sigma_epsilon = 0,
  |sigma_epsilon|_delta^2 = s_epsilon^2.

Define

  h_epsilon^pm := +/- s_epsilon/sqrt(6),

  g_0 := delta,

  K_0^pm := sigma_epsilon + h_epsilon^pm delta.

The exact nonlinear vacuum constraints hold:

  R(g_0) + (tr K_0^pm)^2 - |K_0^pm|^2 = 0,

  div(K_0^pm - (tr K_0^pm)g_0) = 0.

The expanding branch is

  K_0^- = sigma_epsilon - (s_epsilon/sqrt(6)) delta.

Throughout this document, the extrinsic-curvature convention is

  K_ij = -(1/2) L_n g_ij,

with n future-directed unit normal.

THEOREM CIRCULAR_DATA_T2_SYMMETRIC.

  L_X g_0 = 0,

  L_X K_0^pm = 0,
  L_Y K_0^pm = 0.

DERIVATION.

The metric is constant and K_0^pm depends only on z. Therefore all x- and
y-derivatives vanish.

2. EXACT TWIST-ZERO CALCULATION
-------------------------------

For commuting Killing fields X,Y define the twist scalars

  J_X := eps_{abcd} X^a Y^b nabla^c X^d,

  J_Y := eps_{abcd} X^a Y^b nabla^c Y^d.

THEOREM CIRCULAR_DATA_GOWDY_TWIST_ZERO.

For the circular initial data,

  J_X = 0,
  J_Y = 0

on the initial hypersurface.

DERIVATION.

Because X and Y occupy the two orbit directions, only the normal/z components
of nabla X and nabla Y can contribute to the four-dimensional epsilon
contraction. In Gaussian normal coordinates at the initial hypersurface,

  g_xz = g_yz = 0,

  partial_u g_xz = -2 K_xz = 0,
  partial_u g_yz = -2 K_yz = 0.

Equivalently,

  Gamma^z_{u x} = Gamma^u_{z x} = 0,
  Gamma^z_{u y} = Gamma^u_{z y} = 0.

Therefore both twist contractions vanish.

In vacuum, the twist constants are conserved along the T2-symmetric
development. Hence they vanish throughout the development.

STATUS = EXACT_B_TIER_CONDITIONAL_ON_SYMMETRY_INHERITANCE.

3. FUTURE-EXPANDING AREAL SIGN
------------------------------

Let gamma_AB be the metric induced on the T2 orbit, A,B in {x,y}, and define

  R := sqrt(det gamma_AB).

Initially,

  gamma_AB = delta_AB,
  R_0 = 1.

For the frozen sign convention,

  n(log R) = -tr_gamma(K_AB).

Since the TT block has zero two-dimensional trace,

  tr_gamma(K_AB^pm) = 2 h_epsilon^pm.

THEOREM EXPANDING_BRANCH_AREAL_SIGN.

For K_0^-,

  n(R)|_0
    = -2 h_epsilon^- R_0
    = sqrt(2/3) s_epsilon
    > 0.

For K_0^+,

  n(R)|_0 = -sqrt(2/3) s_epsilon < 0.

Therefore K_0^- is future-expanding in areal time and K_0^+ is
future-contracting.

STATUS = EXACT_B_TIER.

Because R is spatially constant initially,

  grad R|_0 = -n(R)n,

and consequently

  gbar(grad R,grad R)|_0 = -n(R)^2 < 0.

Thus the areal gradient is initially timelike.


4. INITIAL RAYCHAUDHURI IDENTITY
--------------------------------

For the expanding branch define

  Theta_0 := -tr K_0^- = sqrt(3/2) s_epsilon.

The shear is sigma_epsilon and

  |sigma_epsilon|^2 = s_epsilon^2.

In vacuum, for the geodesic hypersurface-normal congruence,

  n(Theta)
    = -(1/3)Theta^2 - |sigma|^2.

THEOREM INITIAL_RAYCHAUDHURI_DECELERATION.

At the initial hypersurface,

  n(Theta)|_0
    = -(1/3)(3/2)s_epsilon^2 - s_epsilon^2
    = -(3/2)s_epsilon^2
    = -Theta_0^2.

Thus the expanding branch has positive initial expansion with exact negative
initial acceleration. This does not by itself prove global completeness; the
global Gowdy theorem is used below.

STATUS = EXACT_B_TIER.


5. GENUINELY UNPOLARIZED GOWDY DATA
-----------------------------------

The orbit TT block is

  M(theta)
    := (s_epsilon/sqrt(2))
       [ [ cos theta,  sin theta ],
         [ sin theta, -cos theta ] ].

THEOREM CIRCULAR_DATA_GENUINELY_UNPOLARIZED.

If k != 0, no constant change of the T2 orbit basis diagonalizes M(theta(z))
for every z. Hence the circular datum is generically unpolarized Gowdy data.

DERIVATION.

The eigendirections of M(theta) are rotated by theta/2. Since theta(z)=kz+alpha
is nonconstant, these directions vary with z. Equivalently, for two values
z_1,z_2,

  [M(theta(z_1)),M(theta(z_2))]

is nonzero whenever sin(theta(z_2)-theta(z_1)) is nonzero. Simultaneous
orthogonal diagonalization by one constant orbit basis would require all such
matrices to commute. This fails for k != 0.

STATUS = EXACT_B_TIER.

The standard future-completeness theorem for general Gowdy data, rather than
only the polarized subclass, is therefore the appropriate imported endpoint.

8. OSCILLATION AND CURVATURE-DEFECT DIAGNOSTIC
-----------------------------------------------

The initial Weyl tensors satisfy

  |E_Weyl|^2 = s_epsilon^4/3,

  |H_Weyl|^2 = k^2 s_epsilon^2.

Consider a sequence indexed by j:

  k_j -> infinity,

  s_j^* := s_j exp(-epsilon_j^2 k_j^2/4).

THEOREM HIGH_FREQUENCY_CURVATURE_DEFECT_SCALING.

If

  s_j^* -> 0,

  |k_j| s_j^* -> beta,

then

  |E_Weyl,j|^2 -> 0,

  |H_Weyl,j|^2 -> beta^2.

Thus the metric/extrinsic amplitude may converge to zero while a nonzero
curvature-energy scale survives.

STATUS = EXACT_B_TIER.

This is the explicit circular-family mechanism compatible with a geometric
corrector stress in oscillatory limits. It does not imply instability of one
fixed finite-frequency datum.

THEOREM CIRCULAR_NO_CORRECTOR_SUFFICIENT_GATE.

If

  s_j^* -> 0,

  |k_j| s_j^* -> 0,

then

  |E_Weyl,j|^2 + |H_Weyl,j|^2 -> 0.

Therefore this scaling is a sufficient no-curvature-defect gate for the
circular family.

STATUS = EXACT_B_TIER.
