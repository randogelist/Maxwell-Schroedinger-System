1. FROZEN MATHEMATICAL SETTING
------------------------------

Domain:

  T^3 := (R/Z)^3,
  |T^3| = 1.

Parameters:

  m > 0,
  hbar > 0,
  epsilon0 > 0,
  mu0 > 0,
  q != 0,
  c^2 = 1/(epsilon0 mu0).

Unknowns:

  psi : R x T^3 -> C,
  A   : R x T^3 -> R^3,
  Phi : R x T^3 -> R.

Matter Hilbert space:

  H_m := L^2(T^3; C).

Normalized matter sphere:

  S(H_m) := { psi in H_m : ||psi||_2 = 1 }.

Solenoidal zero-mean Sobolev spaces:

  H^s_{sigma,0}
    := { v in H^s(T^3;R^3) : div v = 0 and mean(v) = 0 }.

Energy configuration space:

  E_energy
    := { (psi,A,E,B) :
           psi in H^1(T^3;C),
           A in H^1_{sigma,0}(T^3;R^3),
           E,B in L^2(T^3;R^3),
           ||psi||_2 = 1 }.

Fermionic profile-transfer space:

  F_-(H_m) := direct_sum_{n>=0} exterior_power^n H_m.

  e_0(x) := 1,

Outsider input and heat regularization:

2. FOURIER–HODGE ALGEBRA
------------------------

Define the mean-zero inverse Laplacian and the associated operators:

  L := (-Delta)_0^{-1},

  P := I + grad L div,

  K := curl L.

For a mean-zero vector distribution F:

  F = -grad L(div F) + curl(KF).

The first term is longitudinal. The second term is transverse.

Coulomb gauge:

  div A = 0,
  mean(A) = 0,
  mean(Phi) = 0.


3. MAXWELL–SCHRÖDINGER SYSTEM
-----------------------------

Covariant derivative:

  D_A := -i hbar grad - q A.

Neutralized periodic charge:

  rho_psi := q(|psi|^2 - 1).

Minimal-coupling matter current:

  J_{psi,A}
    := (q/m) Re(conj(psi) D_A psi).

Electromagnetic fields:

  E := -partial_t A - grad Phi,
  B := curl A.

For a real time-independent binding potential W:

(MS-S)

  i hbar partial_t psi
    = [ D_A^2/(2m) + W + q Phi ] psi.

(MS-G)

  div E = rho_psi/epsilon0,
  div B = 0.

(MS-M)

  partial_t B + curl E = 0,

  partial_t E - c^2 curl B
    = -J_{psi,A}/epsilon0.

Coulomb-gauge reduction:

(MS-C1)

  -Delta Phi = rho_psi/epsilon0.

(MS-C2)

  partial_t^2 A - c^2 Delta A
    = (1/epsilon0) P J_{psi,A}.


4. NATIVE IDENTITIES
---------------------

THEOREM MS_CHARGE_NEUTRALITY.

If ||psi||_2 = 1 and |T^3| = 1, then

  integral_{T^3} rho_psi dx = 0.

DERIVATION.

  integral rho_psi
    = q(integral |psi|^2 - integral 1)
    = q(||psi||_2^2 - 1)
    = 0.


THEOREM MS_CONTINUITY_IDENTITY.

For sufficiently regular solutions of (MS-S), with real A, Phi, and W:

  partial_t |psi|^2
    + div[(1/m) Re(conj(psi) D_A psi)] = 0.

Equivalently:

  partial_t rho_psi + div J_{psi,A} = 0.

DERIVATION.

Multiply (MS-S) by conj(psi), subtract the conjugate equation multiplied by
psi, cancel all real zeroth-order terms, and rewrite the covariant kinetic
remainder as a divergence.


COROLLARY MS_MASS_CONSERVATION.

On the periodic domain:

  d/dt ||psi(t)||_2^2 = 0.


THEOREM MS_CONSTRAINT_PROPAGATION.

Define

  G_E := div E - rho_psi/epsilon0,
  G_B := div B.

Under Ampere, Faraday, and continuity:

  partial_t G_E = 0,
  partial_t G_B = 0.

Hence Gauss constraints imposed at one time persist.


TARGET MS_COULOMB_EQUIVALENCE.

Under Coulomb gauge, zero-mean normalization, sufficient regularity, and
periodic Hodge inversion, prove equivalence between the first-order Maxwell
system and the Poisson–wave system (MS-C1)–(MS-C2).


TARGET MS_TOTAL_ENERGY_CONSERVATION.

Define

  H_MS(psi,A,E,B)
    := (1/(2m)) ||D_A psi||_2^2
       + integral W |psi|^2
       + (epsilon0/2) ||E||_2^2
       + (1/(2mu0)) ||B||_2^2.

For sufficiently regular solutions and static real W, prove

  d/dt H_MS = 0.


5. STATIONARY PROFILE SECTOR
----------------------------

Fix

  chi in C^infinity(T^3;R),
  chi(x) > 0,
  ||chi||_2 = 1,
  lambda in R.

Define

  rho_chi := q(chi^2 - 1),

  -epsilon0 Delta Phi_chi = rho_chi,
  mean(Phi_chi) = 0,

  E_chi := -grad Phi_chi,

  W_chi
    := lambda
       + (hbar^2/(2m))(Delta chi)/chi
       - q Phi_chi.


THEOREM MS_STATIONARY_PROFILE.

The tuple

  psi_*(t,x) = exp(-i lambda t/hbar) chi(x),
  A_*(t,x)   = 0,
  Phi_*(t,x) = Phi_chi(x),
  E_*(x)     = E_chi(x),
  B_*(x)     = 0

solves the Maxwell–Schrödinger system, and

  J_{psi_*,0} = 0,
  partial_t |psi_*|^2 = 0,
  partial_t rho_chi = 0.


THEOREM MS_GROUND_STATE_TRANSFORM.

For every admissible psi and A, set f := psi/chi. Then

  (1/(2m)) ||D_A psi||_2^2
  + (hbar^2/(2m)) integral (Delta chi/chi)|psi|^2

  = (1/(2m)) integral chi^2 |D_A f|^2.

DERIVATION.

Expand D_A(chi f), integrate the real cross term by parts, and use that the
A-dependent scalar cross term is purely imaginary.


THEOREM MS_EXACT_ENERGY_GAP.

For every admissible configuration satisfying Gauss law:

  H_MS(psi,A,E,B) - H_MS(chi,0,E_chi,0)

  = (1/(2m)) integral chi^2 |D_A(psi/chi)|^2
    + (epsilon0/2) ||E-E_chi||_2^2
    + (1/(2mu0)) ||B||_2^2.

DERIVATION.

  1. The lambda term cancels by normalization.
  2. Apply MS_GROUND_STATE_TRANSFORM.
  3. Use

       div(E-E_chi)
         = q(|psi|^2-chi^2)/epsilon0,

     and E_chi = -grad Phi_chi to obtain

       epsilon0 <E_chi,E-E_chi>
         = q integral Phi_chi(|psi|^2-chi^2).

  4. This cancels the term generated by -q Phi_chi in W_chi.
  5. Complete the electric square.


COROLLARY MS_GLOBAL_MINIMIZER.

  H_MS(psi,A,E,B) >= H_MS(chi,0,E_chi,0).

In frozen Coulomb gauge, equality implies

  B = 0,
  E = E_chi,
  A = 0,
  psi = exp(i theta) chi

for a constant theta.


COROLLARY MS_ENERGY_TRAPPING.

Assume a sufficiently regular global solution and energy conservation. Put

  delta
    := H_MS(psi(0),A(0),E(0),B(0))
       - H_MS(chi,0,E_chi,0).

Then for every t:

  (epsilon0/2)||E(t)-E_chi||_2^2 <= delta,

  (1/(2mu0))||B(t)||_2^2 <= delta,

  (1/(2m)) integral chi^2
    |D_{A(t)}(psi(t)/chi)|^2 <= delta.


OPEN MS_ORBITAL_METRIC_COERCIVITY.

Derive a gauge-fixed estimate controlling distance to

  { exp(i theta) chi : theta in R }

by the covariant gap.


CONDITIONAL MS_GLOBAL_ORBITAL_STABILITY.

Assuming global energy-class well-posedness, energy conservation, and
MS_ORBITAL_METRIC_COERCIVITY, the phase orbit of chi is globally orbitally
stable.


6. CREATION–ANNIHILATION / PROFILE TRANSFER
-------------------------------------------

Let a(f), a^dagger(f) satisfy the fermionic CAR on F_-(H_m):

  {a(f),a^dagger(g)} = <f,g>I,
  {a(f),a(g)} = 0,
  {a^dagger(f),a^dagger(g)} = 0.

Define

  C_chi := a^dagger(chi)a(e_0),

  C_chi^dagger := a^dagger(e_0)a(chi).


THEOREM PROFILE_TRANSFER_ONE_PARTICLE.

On the one-particle sector:

  C_chi = |chi><e_0|,
  C_chi^dagger = |e_0><chi|.


THEOREM PROFILE_TRANSFER_COMMUTATOR.

On the one-particle sector:

  C_chi C_chi^dagger = P_chi,
  C_chi^dagger C_chi = P_0,

  [C_chi,C_chi^dagger] = P_chi - P_0.


THEOREM PROFILE_TRANSFER_CHARGE_DIAGONAL.

The kernel diagonal satisfies

  diag(P_chi-P_0)(x) = |chi(x)|^2 - 1.

Hence

  rho_chi(x)
    = q diag([C_chi,C_chi^dagger])(x).

Moreover

  [N_hat,C_chi] = 0.

Thus C_chi transfers one occupied mode into another without changing total
particle number. The subtraction 1 is the uniform reference occupation; it is
not pair annihilation.


THEOREM RELATIVE_CHARGE_SMEARING.

For a test function f, let M_f be multiplication by f and define

  rho_hat_rel(f)
    := q[dGamma(M_f) - (integral f)N_hat].

Then

  <chi|rho_hat_rel(f)|chi>
    = q integral f(x)(|chi(x)|^2-1) dx.


TARGET PROFILE_TRANSFER_UNITARY_ROTATION.

Let c=<e_0,chi>, s=sqrt(1-c^2), and

  xi=(chi-ce_0)/s

when s>0. Define

  G_chi
    := a^dagger(xi)a(e_0)-a^dagger(e_0)a(xi).

Derive the number-preserving unitary rotation

  U_chi := exp(theta G_chi),
  theta := arccos(c),

with

  U_chi |e_0> = |chi>.


7. CONDITIONAL a_DAGGER MAGNETIC EXTENSION
------------------------------------------

Let epsilon>0 and assume a_epsilon is a nonzero smooth solenoidal zero-mean
field obtained from the raw a_dagger datum.

For lambda in R define

  B_lambda := lambda a_epsilon,

  A_lambda := K B_lambda,

  p_lambda := hbar grad theta_lambda - q A_lambda.

Weighted phase equation:

  div(chi^2 p_lambda) = 0,
  mean(theta_lambda) = 0.

Because chi is positive on compact T^3, the operator

  theta |-> -div(chi^2 grad theta)

is uniformly elliptic on the mean-zero scalar sector.


THEOREM WEIGHTED_PHASE_SOLVABILITY.

For smooth Coulomb-gauge A_lambda, there is a unique weak mean-zero
solution theta_lambda of

  hbar div(chi^2 grad theta_lambda)
    = q div(chi^2 A_lambda).

This is B-tier derived; exact formal endpoint and source routing remain pending.

Define

  J_lambda^mat
    := (q/m) chi^2 p_lambda,

  J_lambda^Max
    := (1/mu0) curl B_lambda,

  J_lambda^ext
    := J_lambda^Max - J_lambda^mat,

and

  W_{chi,lambda}
    := E_lambda
       + (hbar^2/(2m))(Delta chi)/chi
       - |p_lambda|^2/(2m)
       - q Phi_chi,

where E_lambda is a real phase eigenvalue.


THEOREM A_DAGGER_STATIC_WITH_CURRENT_DEFECT.

The tuple

  psi_lambda(t,x)
    = exp(-i E_lambda t/hbar)
      chi(x) exp(i theta_lambda(x)),

  A = A_lambda,
  Phi = Phi_chi,
  E = E_chi,
  B = B_lambda

solves the stationary Maxwell–Schrödinger equations with total current

  J_total
    = J_lambda^mat + J_lambda^ext
    = J_lambda^Max.

The charge is independent of lambda:

  rho_lambda = q(chi^2 - 1).


THEOREM STATIC_SPINLESS_MAGNETIC_NO_GO.

Assume

  div(chi^2 p) = 0,

  p = hbar grad theta - qA,

  B = curl A,
  div A = 0,
  mean(A) = 0,

and exact static spinless self-consistency

  (1/mu0)curl B = (q/m)chi^2 p.

Then

  B = 0,
  p = 0,
  A = 0,
  theta = constant.

DERIVATION.

Pair Ampere's equation with A:

  (1/mu0)||B||_2^2
    = (q/m) integral chi^2 p dot A.

Use

  qA = hbar grad theta - p.

Weighted continuity gives

  integral chi^2 p dot grad theta = 0.

Therefore

  (1/mu0)||B||_2^2
    = -(1/m) integral chi^2 |p|^2.

Both nonnegative terms vanish.


COROLLARY NONZERO_DRESSING_REQUIRES_DEFECT.

If lambda != 0 and a_epsilon != 0, then

  J_lambda^ext != 0.

A nonzero static magnetic dressing therefore requires an external current,
spin current, additional matter sector, or time dependence.
