ABSTRACT
--------

This document specifies a periodic spinless Maxwell-Schrodinger system on the
unit three-torus, records its algebraic and analytic identities, constructs a
stationary electrostatic matter profile, derives an exact nonnegative energy
gap, identifies the neutralized charge density as the diagonal of a
number-preserving one-particle transfer commutator, and analyzes a conditional
transverse a_dagger magnetic extension.

The exact core consists of:

  (i)   charge neutrality, gauge covariance, continuity, mass conservation,
        propagation of Maxwell constraints, Coulomb-gauge reduction, and
        total-energy conservation for sufficiently regular solutions;

  (ii)  a stationary profile theorem for every positive normalized smooth
        profile chi with a reconstructed binding potential;

  (iii) an exact ground-state transform and exact energy-gap identity;

  (iv)  a number-preserving creation-annihilation profile-transfer algebra;

  (v)   a stationary regularized a_dagger magnetic extension with an explicit
        current defect;

  (vi)  a static spinless magnetic no-go theorem excluding nonzero magnetic
        self-consistency for one positive scalar matter profile.

The regularity/photon-radius interpretation remains conditional on named NSE
and coherent-state premises. No physical phase transition is inferred from the
certificate radius alone.

1. GEOMETRIC, ALGEBRAIC, AND FUNCTIONAL SETTING
------------------------------------------------

1.1 Domain and constants
~~~~~~~~~~~~~~~~~~~~~~~~

  T^3 := (R/Z)^3,
  |T^3| = 1.

  m > 0,
  hbar > 0,
  epsilon0 > 0,
  mu0 > 0,
  q != 0,
  c^2 = 1/(epsilon0 mu0).

Spatial means are denoted by

  <f> := integral_{T^3} f(x) dx.

The Laplacian convention is

  Delta := sum_{j=1}^3 partial_j^2,

so -Delta is nonnegative.

1.2 Scalar and vector spaces
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  L2_m := L^2(T^3; C),

  S(L2_m) := {psi in L2_m : ||psi||_2 = 1},

  H^s_{sigma,0}
    := {v in H^s(T^3; R^3) : div v = 0 and <v> = 0},

  H^s_0
    := {f in H^s(T^3) : <f> = 0}.

The strong configuration class is

  X_strong
    := { (psi,A,Phi,E,B) :
           psi, A, Phi, E, B are smooth,
           ||psi||_2 = 1,
           A in H^s_{sigma,0},
           <Phi> = 0 }.

The energy configuration class is

  X_energy
    := { (psi,A,E,B) :
           psi in H^1(T^3; C),
           A in H^1_{sigma,0},
           E,B in L^2(T^3; R^3),
           ||psi||_2 = 1,
           B = curl A,
           div E = q(|psi|^2-1)/epsilon0 }.

The B-tier conservation derivations are asserted first for sufficiently smooth
solutions. Extension to weak energy solutions is a separate compactness and
lower-semicontinuity endpoint.

1.3 Fourier-Hodge operators
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Let

  L := (-Delta)_0^{-1}

be the zero-mean inverse of -Delta. Define

  P := I + grad L div,
  K := curl L.

For every mean-zero smooth vector field F,

  -Delta L F = F,

  P F = F + grad L(div F),

  div(P F) = 0,

  curl(K F) = P F,

  div(K F) = 0,

  F = -grad L(div F) + curl(K F).

Thus

  longitudinal(F) = -grad L(div F),
  transverse(F)   = P F = curl(K F).

For B in H^s_{sigma,0},

  curl(K B) = B.

1.4 Coulomb gauge
~~~~~~~~~~~~~~~~~

  div A = 0,
  <A> = 0,
  <Phi> = 0.

In this gauge, the vector potential is uniquely recovered from B by

  A = K B.

1.5 Matter and electromagnetic definitions
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Define the covariant momentum

  D_A := -i hbar grad - q A.

Define charge and current

  rho_psi := q(|psi|^2 - 1),

  J_{psi,A}
    := (q/m) Re( conjugate(psi) D_A psi )
     = (q hbar/m) Im(conjugate(psi) grad psi)
       - (q^2/m) A |psi|^2.

Define fields

  E := -partial_t A - grad Phi,
  B := curl A.

1.6 Fermionic one-particle and Fock spaces
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  H_1 := L^2(T^3; C),

  F_-(H_1) := direct_sum_{n>=0} wedge^n H_1,

  e_0(x) := 1,
  ||e_0||_2 = 1.

Creation and annihilation operators satisfy the canonical anticommutation
relations

  {a(f),a^dagger(g)} = <f,g> I,
  {a(f),a(g)} = 0,
  {a^dagger(f),a^dagger(g)} = 0.

1.7 a_dagger sector
~~~~~~~~~~~~~~~~~~~

A raw transverse datum a_dagger is assumed to be a mean-zero divergence-free
periodic distribution. For epsilon>0 define

  a_epsilon := exp((epsilon^2/4) Delta) a_dagger.

The exact outsider properties

  a_dagger in L^2_{sigma,0},
  a_dagger notin BMO^{-1},
  precise Sobolev threshold,

remain a separate source endpoint unless proved from the explicit raw series.


2. MAXWELL-SCHRODINGER EQUATIONS
--------------------------------

Let W:T^3->R be real and time-independent.

The Schrodinger equation is

(MS-S)

  i hbar partial_t psi
    = [ (1/(2m)) D_A^2 + W + q Phi ] psi.

The first-order Maxwell equations are

(MS-GE)

  div E = rho_psi/epsilon0,

(MS-GB)

  div B = 0,

(MS-F)

  partial_t B + curl E = 0,

(MS-A)

  partial_t E - c^2 curl B = -J_{psi,A}/epsilon0.

The potential identities are

  E = -partial_t A - grad Phi,
  B = curl A.

The Coulomb-gauge reduced equations are

(MS-P)

  -Delta Phi = rho_psi/epsilon0,

(MS-W)

  partial_t^2 A - c^2 Delta A
    = (1/epsilon0) P J_{psi,A}.


3. GAUGE COVARIANCE AND COULOMB-GAUGE EQUIVALENCE
--------------------------------------------------

THEOREM MS_GAUGE_COVARIANCE.

For a sufficiently regular real scalar Lambda, define

  psi' = exp(i q Lambda/hbar) psi,
  A'   = A + grad Lambda,
  Phi' = Phi - partial_t Lambda.

Then

  D_{A'} psi' = exp(i q Lambda/hbar) D_A psi,

and

  |psi'|^2 = |psi|^2,
  rho_{psi'} = rho_psi,
  J_{psi',A'} = J_{psi,A},
  E' = E,
  B' = B.

Consequently the Maxwell-Schrodinger equations and total energy are gauge
covariant.

DERIVATION.

Differentiate exp(i q Lambda/hbar) psi. The q grad Lambda term generated by the
phase derivative cancels the added q grad Lambda in A'. The time derivative
produces -q partial_t Lambda, which is canceled by q Phi'. The field identities
follow directly.


THEOREM MS_COULOMB_EQUIVALENCE.

Assume Coulomb gauge, zero means, sufficient regularity, and the continuity
equation. Then the first-order Maxwell system (MS-GE)--(MS-A) is equivalent to
(MS-P)--(MS-W) together with

  E = -partial_t A - grad Phi,
  B = curl A.

DERIVATION: FIRST-ORDER TO REDUCED.

Gauss law and div(partial_t A)=0 give

  -Delta Phi = rho_psi/epsilon0.

Using curl curl A = grad div A - Delta A = -Delta A, Ampere gives

  -partial_t^2 A - grad partial_t Phi + c^2 Delta A
    = -J/epsilon0.

Applying P annihilates the gradient term and yields

  partial_t^2 A - c^2 Delta A = P J/epsilon0.

DERIVATION: REDUCED TO FIRST-ORDER.

Faraday and div B follow identically from the potential definitions. Gauss law
is (MS-P). Apply P to Ampere to obtain its transverse component from (MS-W).
The longitudinal component follows by differentiating (MS-P) and using

  partial_t rho + div J = 0.

Therefore the complete Ampere equation follows.

4. NEUTRALITY, CONTINUITY, MASS, AND CONSTRAINT PROPAGATION
-----------------------------------------------------------

THEOREM MS_CHARGE_NEUTRALITY.

If ||psi||_2=1, then

  integral_{T^3} rho_psi dx
    = q( ||psi||_2^2 - 1 )
    = 0.

Thus the periodic Poisson equation is compatible.


THEOREM MS_CONTINUITY_IDENTITY.

Assume psi solves (MS-S), with real A, Phi, and W. Then

  partial_t |psi|^2
    + div[ (1/m) Re(conjugate(psi) D_A psi) ]
    = 0,

and hence

  partial_t rho_psi + div J_{psi,A} = 0.

DERIVATION.

Multiply (MS-S) by conjugate(psi), subtract the conjugate equation multiplied
by psi, and divide by i hbar. The real zeroth-order terms cancel. The covariant
kinetic difference is the divergence of the minimal-coupling current.


COROLLARY MS_MASS_CONSERVATION.

For periodic sufficiently regular solutions,

  d/dt ||psi(t)||_2^2 = 0.


THEOREM MS_CONSTRAINT_PROPAGATION.

Define

  G_E := div E - rho_psi/epsilon0,
  G_B := div B.

If Ampere, Faraday, and continuity hold, then

  partial_t G_E = 0,
  partial_t G_B = 0.

Therefore Gauss constraints imposed at one time persist for all times of
existence.

DERIVATION.

Take divergence of Ampere and use div curl B=0 and continuity. Take divergence
of Faraday and use div curl E=0.


5. TOTAL-ENERGY CONSERVATION
----------------------------

Define the matter energy

  H_mat(psi,A)
    := (1/(2m)) ||D_A psi||_2^2
       + integral_{T^3} W |psi|^2 dx.

Define the electromagnetic energy

  H_EM(E,B)
    := (epsilon0/2)||E||_2^2
       + (1/(2 mu0))||B||_2^2.

Define

  H_MS := H_mat + H_EM.

THEOREM MS_TOTAL_ENERGY_CONSERVATION.

Assume a sufficiently regular solution of the complete Maxwell-Schrodinger
system, periodic boundary conditions, and real time-independent W. Then

  d/dt H_MS = 0.

DERIVATION: MATTER PART.

Differentiate H_mat. Use

  partial_t D_A = -q partial_t A,

insert the Schrodinger equation, integrate covariant derivatives by parts, and
use E=-partial_t A-grad Phi. All Hamiltonian commutator terms cancel. The
remaining power identity is

  d/dt H_mat = integral_{T^3} J_{psi,A} dot E dx.

DERIVATION: FIELD PART.

Pair Ampere with epsilon0 E and Faraday with B/mu0. Since

  epsilon0 c^2 = 1/mu0,

periodic integration by parts gives

  d/dt H_EM
    = -integral_{T^3} J_{psi,A} dot E dx.

Summing the two identities yields the result.

STATUS = EXACT_B_TIER_FOR_SMOOTH_SOLUTIONS.

Weak-solution conservation or inequality requires a separate approximation and
limit theorem.


6. STATIONARY PROFILE CONSTRUCTION
----------------------------------

Fix

  chi in C^infinity(T^3; R),
  chi(x)>0,
  ||chi||_2=1,
  lambda in R.

Define

  rho_chi := q(chi^2-1),

  -epsilon0 Delta Phi_chi = rho_chi,
  <Phi_chi>=0,

  E_chi := -grad Phi_chi,

and

  W_chi
    := lambda
       + (hbar^2/(2m))(Delta chi)/chi
       - q Phi_chi.

THEOREM MS_STATIONARY_PROFILE.

The fields

  psi_*(t,x) = exp(-i lambda t/hbar) chi(x),
  A_*(t,x)   = 0,
  Phi_*(t,x) = Phi_chi(x),
  E_*(x)     = E_chi(x),
  B_*(x)     = 0

solve the Maxwell-Schrodinger system and satisfy

  J_{psi_*,0}=0,
  partial_t |psi_*|^2=0,
  partial_t rho_chi=0,
  partial_t E_chi=0,
  partial_t B_*=0.

DERIVATION.

Because chi is real,

  Re(chi(-i hbar grad chi))=0.

The Schrodinger right-hand side is

  -(hbar^2/(2m))Delta chi
  + W_chi chi
  + q Phi_chi chi
  = lambda chi.

The Maxwell equations reduce to the Poisson equation for Phi_chi.

STATUS = EXACT_B_TIER.


7. GROUND-STATE TRANSFORM AND EXACT ENERGY GAP
----------------------------------------------

Let

  f := psi/chi.

THEOREM MS_GROUND_STATE_TRANSFORM.

For psi in H^1 and admissible A,

  (1/(2m))||D_A psi||_2^2
  + (hbar^2/(2m)) integral (Delta chi/chi)|psi|^2 dx

  = (1/(2m)) integral chi^2 |D_A f|^2 dx.

DERIVATION.

Expand

  D_A(chi f) = chi D_A f - i hbar f grad chi.

The A-dependent part of the cross term is purely imaginary and has zero real
part. Integrate the remaining gradient cross term by parts. The scalar
remainder is exactly canceled by the displayed Delta chi/chi term.


THEOREM MS_EXACT_ENERGY_GAP.

For every configuration in X_energy, with W=W_chi,

  H_MS(psi,A,E,B) - H_MS(chi,0,E_chi,0)

  = (1/(2m)) integral chi^2 |D_A(psi/chi)|^2 dx
    + (epsilon0/2)||E-E_chi||_2^2
    + (1/(2 mu0))||B||_2^2.

DERIVATION.

Step 1. The lambda contribution cancels because

  ||psi||_2=||chi||_2=1.

Step 2. Apply MS_GROUND_STATE_TRANSFORM.

Step 3. Gauss law gives

  div(E-E_chi)
    = q(|psi|^2-chi^2)/epsilon0.

Step 4. Since E_chi=-grad Phi_chi,

  epsilon0 <E_chi,E-E_chi>
    = q integral Phi_chi(|psi|^2-chi^2) dx.

Step 5. This term cancels the linear contribution generated by

  -q Phi_chi

inside W_chi. Complete the electric square. The magnetic term is already
nonnegative.

STATUS = EXACT_B_TIER.


8. MINIMIZATION AND ENERGY TRAPPING
-----------------------------------

COROLLARY MS_GLOBAL_MINIMIZER.

  H_MS(psi,A,E,B) >= H_MS(chi,0,E_chi,0).

In frozen Coulomb gauge, equality implies

  E=E_chi,
  B=0,
  A=0,
  psi=exp(i theta)chi

for a constant theta.

DERIVATION OF THE EQUALITY CASE.

The three gap terms vanish. B=0 and the zero-mean Coulomb gauge imply A=0.
Then

  grad(psi/chi)=0,

so psi/chi is constant. Normalization fixes its modulus to one.


COROLLARY MS_ENERGY_TRAPPING.

For every sufficiently regular global solution with conserved energy define

  delta
    := H_MS(psi(0),A(0),E(0),B(0))
       - H_MS(chi,0,E_chi,0).

Then for every time of existence,

  (epsilon0/2)||E(t)-E_chi||_2^2 <= delta,

  (1/(2mu0))||B(t)||_2^2 <= delta,

  (1/(2m)) integral chi^2
    |D_{A(t)}(psi(t)/chi)|^2 dx <= delta.

A quantitative estimate in a fixed orbital metric is a separate endpoint:

  MS_ORBITAL_METRIC_COERCIVITY.

Global orbital stability additionally requires global well-posedness in the
chosen energy class.


9. NUMBER-PRESERVING PROFILE-TRANSFER ALGEBRA
---------------------------------------------

Define on fermionic Fock space

  C_chi := a^dagger(chi)a(e_0),
  C_chi^dagger := a^dagger(e_0)a(chi).

THEOREM PROFILE_TRANSFER_ONE_PARTICLE.

On the one-particle sector H_1,

  C_chi = |chi><e_0|,
  C_chi^dagger = |e_0><chi|,

  C_chi C_chi^dagger = P_chi,
  C_chi^dagger C_chi = P_0,

  [C_chi,C_chi^dagger] = P_chi-P_0.

The integral-kernel diagonal satisfies

  diag(P_chi-P_0)(x)=|chi(x)|^2-1.

Hence

  rho_chi(x)
    = q diag([C_chi,C_chi^dagger])(x)

on the one-particle sector.

The transfer preserves total particle number:

  [N_hat,C_chi]=0.


THEOREM RELATIVE_CHARGE_SMEARING.

For a bounded test multiplier M_f define

  rho_hat_rel(f)
    := q[ dGamma(M_f) - (integral f) N_hat ].

Then

  <chi|rho_hat_rel(f)|chi>
    = q integral f(x)(|chi(x)|^2-1) dx.

The uniform subtraction is a neutralizing reference occupation; it is not pair
annihilation.


THEOREM PROFILE_TRANSFER_UNITARY_ROTATION.

Let

  c_0 := <e_0,chi>.

Because chi is positive and normalized,

  0 < c_0 <= 1.

If c_0=1, then chi=e_0 and the identity operator performs the transfer.
If c_0<1, define

  s_0 := sqrt(1-c_0^2),
  xi  := (chi-c_0 e_0)/s_0,
  theta_0 := arccos(c_0),

and

  G_chi
    := a^dagger(xi)a(e_0)-a^dagger(e_0)a(xi).

Then G_chi is anti-self-adjoint on the finite two-mode sector and

  U_chi := exp(theta_0 G_chi)

is number-preserving and unitary. On the one-particle sector,

  U_chi e_0 = chi.

10. REGULARIZED a_DAGGER MAGNETIC EXTENSION
-------------------------------------------

THEOREM A_DAGGER_HEAT_REGULARIZATION.

Let a_dagger be any periodic distribution. For epsilon>0,

  a_epsilon=exp((epsilon^2/4)Delta)a_dagger

is smooth. If

  div a_dagger=0,
  <a_dagger>=0,

in distributions, then

  div a_epsilon=0,
  <a_epsilon>=0.

DERIVATION.

The periodic heat multiplier is

  exp(-pi^2 epsilon^2 |k|^2)

on Fourier mode k. It suppresses every polynomial Fourier growth and commutes
with derivatives and the zero-mode projection.

For lambda in R define

  B_lambda := lambda a_epsilon,
  A_lambda := K B_lambda.

Then

  div A_lambda=0,
  <A_lambda>=0,
  curl A_lambda=B_lambda.

Weighted stationarity requires

  div[chi^2(hbar grad theta_lambda-qA_lambda)]=0,
  <theta_lambda>=0.

THEOREM WEIGHTED_PHASE_SOLVABILITY.

For positive smooth chi and smooth A_lambda, the weighted phase equation has a
unique mean-zero weak solution theta_lambda.

DERIVATION.

On H^1_0(T^3), define

  a(theta,eta)
    := hbar integral chi^2 grad theta dot grad eta,

  ell(eta)
    := q integral chi^2 A_lambda dot grad eta.

Since min chi>0, a is bounded and coercive by the periodic Poincare inequality.
ell is bounded. Lax-Milgram gives existence and uniqueness. Elliptic regularity
gives smoothness for smooth data.

Define

  p_lambda := hbar grad theta_lambda-qA_lambda,

  J_lambda^mat := (q/m)chi^2 p_lambda,

  J_lambda^Max := (1/mu0)curl B_lambda,

For a real phase eigenvalue E_lambda define

  W_{chi,lambda}
    := E_lambda
       + (hbar^2/(2m))(Delta chi)/chi
       - |p_lambda|^2/(2m)

THEOREM A_DAGGER_STATIC_WITH_CURRENT_DEFECT.

The fields

  psi_lambda(t,x)
    = exp(-i E_lambda t/hbar)
      chi(x)exp(i theta_lambda(x)),

  A=A_lambda,
  Phi=Phi_chi,
  E=E_chi,
  B=B_lambda,

with total current

  J_total=J_lambda^mat+J_lambda^ext

solve the stationary Maxwell-Schrodinger equations. The charge is

  rho_lambda=q(chi^2-1),

independent of lambda. The magnetic incompatibility is exactly
J_lambda^ext.

11. STATIC SPINLESS MAGNETIC NO-GO THEOREM
------------------------------------------

THEOREM STATIC_SPINLESS_MAGNETIC_NO_GO.

Assume

  div(chi^2 p)=0,

  p=hbar grad theta-qA,

  B=curl A,
  div A=0,
  <A>=0,

and exact spinless static self-consistency

  (1/mu0)curl B=(q/m)chi^2 p.

Then

  B=0,
  p=0,
  A=0,
  theta=constant.

DERIVATION.

Pair Ampere's equation with A:

  (1/mu0)||B||_2^2
    = (q/m) integral chi^2 p dot A.

Use

  qA=hbar grad theta-p.

The weighted continuity equation gives

  integral chi^2 p dot grad theta=0.

Therefore

  (1/mu0)||B||_2^2
    = -(1/m) integral chi^2|p|^2.

Both nonnegative quantities vanish. The gauge conditions then imply A=0 and
theta is constant.

COROLLARY NONZERO_DRESSING_REQUIRES_DEFECT.

If

  lambda!=0,
  a_epsilon!=0,

then

  J_lambda^ext!=0.

Thus a nonzero static magnetic dressing requires at least one of:

  external current,
  spin current,
  additional matter species,
  nonstationary evolution,
  modified coupling law.

STATUS = EXACT_B_TIER.


12. CONDITIONAL REGULARITY / PHOTON-RADIUS BRIDGE
-------------------------------------------------

PREMISE NSE_REGULARITY_CERTIFICATE(nu,epsilon).

There exist K2>0 and p(a_epsilon)>0 such that

  |lambda| < lambda_crit

with

  lambda_crit
    := sqrt(2)nu/[K2 p(a_epsilon)]

implies

  Reg_nu(lambda a_epsilon).

PREMISE COHERENT_RAY_LAWS(epsilon).

For a fixed quantization convention there exist N_1>0 and E_1>0 such that

  N_gamma(lambda)=lambda^2 N_1,
  E_gamma(lambda)=lambda^2 E_1.

Define

  N_crit=lambda_crit^2 N_1,
  E_crit=lambda_crit^2 E_1.

THEOREM CERTIFICATE_RADIUS_TRANSLATION.

Under the two named premises,

  |lambda|<lambda_crit
    iff N_gamma(lambda)<N_crit
    iff E_gamma(lambda)<E_crit.

This theorem translates one sufficient regularity certificate along one
coherent ray. It does not establish:

  singularity at equality,
  singularity above the radius,
  a Maxwell phase transition,
  a photon-production threshold,
  regulator-independent physical criticality.

A physical threshold claim requires both

  PHYSICAL_THRESHOLD_LIMIT

and

  QED_TO_NSE_DYNAMICAL_BRIDGE.
