0. FROZEN PERIODIC QFB SCOPE
----------------------------

Let

  T^3 := (R/Z)^3,

with volume one. Let

  nu > 0,
  a in L^2_{sigma,0}(T^3),

and let u be an unforced Leray-Hopf solution with initial datum a.

Set

  M := ||a||_2.

For a sufficiently regular time t define

  E(t) := ||u(t)||_2^2,
  D(t) := ||grad u(t)||_2^2,
  H(t) := ||u(t)||_{dot H^{1/2}}^2.

The frozen QFB admission endpoint is

  QFB_ADMISSION:

    H(b) < 2 pi nu^2
      implies
    Reg_nu(b).

Here Reg_nu(b) denotes a global smooth strong solution from datum b, together
with weak-strong uniqueness against the Leray-Hopf trajectory after the
restart time.


1. LERAY-HOPF BUDGET
--------------------

The energy inequality gives

  E(t) + 2 nu integral_0^t D(s) ds <= M^2,

hence

  E(t) <= M^2,

  integral_0^infinity D(s) ds <= M^2/(2 nu).

The interpolation inequality is

  H(t)^2 <= E(t) D(t).

Therefore, for every delta>0,

  integral_0^delta H(t)^2 dt
    <= integral_0^delta E(t)D(t) dt
    <= M^2 integral_0^delta D(t) dt
    <= M^4/(2 nu).

2. GOOD RESTART TIME
--------------------

Define

  T_QFB(a,nu)
    := M^4/(8 pi^2 nu^5).

Let

  delta > T_QFB(a,nu).

Then

  M^4/(2 nu delta) < 4 pi^2 nu^4.

By the integral budget, there exists a regular/Lebesgue time

  s in (0,delta)

such that

  H(s)^2
    <= M^4/(2 nu delta)
    < 4 pi^2 nu^4.

Since H(s)>=0,

  H(s) < 2 pi nu^2.

QFB_ADMISSION therefore yields a global smooth restart from u(s). By
weak-strong uniqueness, the original Leray-Hopf trajectory agrees with this
smooth solution for all t>=s. In particular it is smooth on [delta,infinity).

THEOREM PERIODIC_QFB_TAIL_REGULARITY.

For every delta satisfying

  delta > T_QFB(a,nu),

the trajectory u is smooth on

  [delta,infinity).

3. EXACT ENDPOINT SEMANTICS
---------------------------

Because delta must satisfy the strict inequality

  delta > T_QFB,

the theorem proves

  u is smooth for every t>T_QFB.

Equivalently, possible positive singular times satisfy

  Sing_t(u) subset (0,T_QFB].

The theorem does not prove regularity at

  t=T_QFB.

It also does not prove uniqueness from the original L2 datum at t=0.
Uniqueness is obtained only after a good regular restart time s.

No recursive halving

  T_QFB -> T_QFB/2 -> T_QFB/4 -> ...

follows from this argument. Such a step would require a new restart estimate
whose input is controlled at the earlier cutoff.

4. DISTINCTION FROM ENERGY-REFINED QFA
--------------------------------------

The distinct whole-space QFA energy refinement uses a sharper budget of the
form

  integral E(t)D(t) dt <= M^4/(4 nu)

and a restart criterion

  E(s)D(s) < 4 pi^2 nu^4.

That chain gives

  T_QFA,E(a,nu)
    = M^4/(16 pi^2 nu^5).

Therefore

  T_QFA,E = T_QFB/2

at the level of the displayed constants, but only under the QFA hypotheses and
restart theorem.

The implication

  periodic QFB cutoff = M^4/(16 pi^2 nu^5)

is not established.

5. PHYSICAL TORUS CONVENTION
----------------------------

Let

  T_L^3 := (R/LZ)^3

with unnormalized physical measure dx and volume

  V=L^3.

For physical initial velocity a, define

  M_phys^2 := integral_{T_L^3} |a(x)|^2 dx.

The NSE scaling from T_L^3 to the unit torus preserves the formula

  T_QFB^phys(a,nu)
    = M_phys^4/(8 pi^2 nu^5).

If instead one uses the normalized spatial average

  ||a||_{2,av}^2
    := L^{-3} integral |a|^2 dx,

then

  T_QFB^phys(a,nu)
    = L^6 ||a||_{2,av}^4/(8 pi^2 nu^5).

Thus the volume convention must be stated before substituting a profile.

6. CIRCULAR NSE PROFILE
-----------------------

Let

  k := 2 pi n/L,
  n in Z, n != 0,

and define

  r0 := |lambda| s exp(-epsilon^2 k^2/4).

The mean-zero circular fluctuation is

  a_epsilon(z)
    := r0 (cos(kz+alpha), sin(kz+alpha), 0).

Because

  |a_epsilon(x)|^2 = r0^2,

one has, with unnormalized physical measure,

  ||a_epsilon||_2^2 = L^3 r0^2,

  ||a_epsilon||_2^4 = L^6 r0^4.

Therefore the canonical periodic QFB cutoff becomes

  T_QFB^circ
    = L^6 r0^4/(8 pi^2 nu^5)

    = L^6 lambda^4 s^4 exp(-epsilon^2 k^2)
      /(8 pi^2 nu^5).

STATUS = EXACT_B_TIER_SUBSTITUTION.

A constant mean transport U0 e3 is removed before applying the mean-zero QFB
theorem. Equivalently, apply QFB to the fluctuation in the comoving frame.


7. ENERGY FORM
--------------

Let rho_f>0 be the declared physical mass density and define the fluctuation
kinetic energy

  E_NSE(0)
    := (rho_f/2) ||a_epsilon||_2^2
     = (rho_f L^3/2) r0^2.

Then

  ||a_epsilon||_2^2 = 2 E_NSE(0)/rho_f,

  ||a_epsilon||_2^4 = 4 E_NSE(0)^2/rho_f^2.

Hence

  T_QFB^circ
    = E_NSE(0)^2/(2 pi^2 rho_f^2 nu^5).

STATUS = EXACT_B_TIER.

This is the exact energy expression for the frozen periodic QFB constant and
the unnormalized physical L2 convention.


8. RELATION TO THE EXACT CIRCULAR DECAY TIMES
----------------------------------------------

The exact circular NSE solution has

  T_amp    = 1/(nu k^2),
  T_energy = 1/(2 nu k^2).

The QFB certificate ratios are

  T_QFB^circ/T_amp
    = L^6 r0^4 k^2/(8 pi^2 nu^4)

    = E_NSE(0)^2 k^2/(2 pi^2 rho_f^2 nu^4),

and

  T_QFB^circ/T_energy
    = L^6 r0^4 k^2/(4 pi^2 nu^4)

    = E_NSE(0)^2 k^2/(pi^2 rho_f^2 nu^4).

These are different notions:

  T_amp:
    amplitude e-folding time of the exact eigenmode;

  T_energy:
    kinetic-energy e-folding time of the exact eigenmode;

  T_QFB:
    worst-case waiting time after which every admissible trajectory with the
    same initial L2 datum is certified regular.

For the explicit circular solution itself,

  actual regularity gap = 0.

Thus T_QFB^circ is conservative and is not the onset time of regularity for
that explicit solution.

9. CERTIFIED TAIL CLOCK
-----------------------

Define

  tau := t-T_QFB^circ.

For a general QFB trajectory, regularity is certified only for

  tau>0.

The value tau=0 is not included by the theorem.

For the explicit circular solution, which is smooth for all t>=0, one may
compute the exact readouts at the certificate location:

  r(T_QFB^circ)
    = r0 exp(-nu k^2 T_QFB^circ),

  E_NSE(T_QFB^circ)
    = E_NSE(0) exp(-2 nu k^2 T_QFB^circ).

If the lab-frame phase clock satisfies

  k U0 = Delta_E/hbar,

then the accumulated phase displacement across the certificate window is

  Delta_phi_QFB
    = -(Delta_E/hbar) T_QFB^circ

modulo 2 pi.

This phase and decay evaluation applies to the explicit circular solution. It
is not an exact formula for an arbitrary Leray-Hopf trajectory covered only by
QFB.

11. ROOT ENDPOINT
-----------------

THEOREM QFB_NSE_TIME_GAP.

Under the frozen periodic Quasi-Fefferman_B theorem,

  T_gap^QFB(a,nu)
    = ||a||_2^4/(8 pi^2 nu^5).

For every

  delta>T_gap^QFB,

every admissible Leray-Hopf trajectory is smooth on [delta,infinity).
Consequently it is smooth for all t>T_gap^QFB, while t=T_gap^QFB remains
uncertified.

For the circular fluctuation on T_L^3,

  T_gap^{QFB,circ}
    = L^6 r0^4/(8 pi^2 nu^5)
    = E_NSE(0)^2/(2 pi^2 rho_f^2 nu^5).

For the explicit circular trajectory, the actual regularity gap is zero.
