0. PHYSICAL TORUS AND MODE
--------------------------

Let

  T_L^3 := (R/LZ)^3,
  V := L^3,
  m_e > 0,
  hbar > 0,
  nu > 0,
  n in Z, n != 0,
  k := 2 pi n/L.

Let

  theta(z) := k z + alpha.

Choose the periodic two-component Pauli spinor

  psi_{n,alpha}(z)
    := L^(-3/2)/sqrt(2)
       ( 1,
         exp(i theta(z)) )^T.

It satisfies

  integral_{T_L^3} psi^dagger psi dx = 1.

Thus it lies in the frozen one-electron sector.


1. DENSITY AND SPIN TEXTURE
---------------------------

The number density is constant:

  n_psi
    := psi^dagger psi
     = L^(-3).

In particular,

  n_psi > 0

pointwise, so the local current velocity is globally defined.

The normalized Bloch spin vector is

  s_psi
    := (psi^dagger sigma psi)/(psi^dagger psi)
     = (cos theta, sin theta, 0).

It satisfies

  div s_psi = 0,
  mean(s_psi) = 0,
  curl s_psi = -k s_psi,
  Delta s_psi = -k^2 s_psi.

2. COMPLETE PAULI CURRENT
-------------------------

Set the electromagnetic vector potential to zero. The Pauli number current is

  j_psi
    = j_tr + j_spin,

where

  j_tr
    := (hbar/m_e) Im(psi^dagger grad psi),

  j_spin
    := (hbar/(2m_e))
       curl(psi^dagger sigma psi).

Direct calculation gives

  j_tr
    = n_psi [hbar k/(2m_e)] e_3,

and, since n_psi is constant,

  j_spin
    = -n_psi [hbar k/(2m_e)] s_psi.

Define

  U_e := hbar k/(2m_e).

Then the local full-current velocity is

  v_psi
    := j_psi/n_psi
     = U_e e_3 - U_e s_psi.

Its spatial mean is

  mean(v_psi)=U_e e_3.

Let P_0 be the L2-orthogonal projection onto real mean-zero divergence-free
vector fields. Since s_psi is already mean-zero and divergence-free,

  a_psi
    := P_0 v_psi
     = -U_e s_psi.

Therefore

  a_psi(z)
    = -[hbar k/(2m_e)]
      (cos(kz+alpha), sin(kz+alpha), 0).

7. FREE ELECTRON PHASE CLOCK
----------------------------

  H_free = -(hbar^2/(2m_e))Delta,

the two spinor components have energies

  E_0 = 0,
  E_1 = hbar^2 k^2/(2m_e).

  omega_e

    = k [hbar k/(2m_e)]
    = hbar k^2/(2m_e)
    = omega_e.
