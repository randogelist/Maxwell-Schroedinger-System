# derivation_of_QM_GR_LOCAL_DARBOUX_MATCHING

```text
ID = GRTT-03
STATUS = EXACT_B_TIER
```

On a CP1 chart define `J=hbar sin^2(theta/2)`, so

```text
Omega_QM=dJ wedge dphi.
```

For any `S>0`, the local coordinates

```text
Q=sqrt(2J/S) cos(phi)
P=sqrt(2J/S) sin(phi)
```

satisfy `S dQ wedge dP=Omega_QM`. Therefore local Darboux matching cannot
select a physical scale.
