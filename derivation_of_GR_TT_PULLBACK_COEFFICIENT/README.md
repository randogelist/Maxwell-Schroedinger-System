# derivation_of_GR_TT_PULLBACK_COEFFICIENT

```text
ID = GRTT-06
STATUS = CONDITIONAL_B_TIER
```

The reduced coefficient is

```text
kappa_TT=A^2 sigma I_TT R^2/(32 pi)
Omega_GR_red=kappa_TT(c^3 epsilon^2/G)omega_FS.
```

Under same-orbit identification and symplectic matching with
`Omega_QM=hbar omega_FS`, one obtains

```text
epsilon=l_P/sqrt(kappa_TT).
```
