Set `z_a=(Q_a+iP_a)/sqrt(2)`, fix `sum |z_a|^2=R^2`, and quotient by common
phase. The quotient is `S^3_R/U(1)=CP1`.

North/south potentials differ by `S_epsilon R^2 dphi`; their common curvature
is

```text
Omega_GR_red=S_epsilon R^2 omega_FS.
```

This reduction produces the required non-exact global two-form.
