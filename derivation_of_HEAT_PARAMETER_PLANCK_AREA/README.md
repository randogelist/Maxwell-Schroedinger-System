Let

```text
tau_epsilon = epsilon^2/4,
exp((epsilon^2/4) Delta) = exp(tau_epsilon Delta).
```

For the coefficient `kappa=1/4`:

```text
S_epsilon = hbar
iff c^3 tau_epsilon/G = hbar
iff tau_epsilon = l_P^2
iff epsilon = 2 l_P.
```

`tau_epsilon` has dimension length squared; it is not physical time without an additional diffusion coefficient.
