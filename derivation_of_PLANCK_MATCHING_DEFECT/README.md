# derivation_of_PLANCK_MATCHING_DEFECT

```text
ENDPOINT_ID = QMGR-15
STATUS = EXACT_B_TIER
```

Define

```text
D_{kappa,epsilon} = kappa epsilon^2/l_P^2 - 1.
```

For fixed `kappa>0`, this is strictly increasing on `epsilon>0`, with unique zero

```text
epsilon_match = l_P/sqrt(kappa).
```

For `kappa=1/4`, the zero is `2 l_P`. This gives a scalar residual for analytical or numerical GR pullback calculations.
