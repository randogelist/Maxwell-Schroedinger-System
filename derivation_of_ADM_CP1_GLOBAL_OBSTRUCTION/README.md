# derivation_of_ADM_CP1_GLOBAL_OBSTRUCTION

```text
ID = GRTT-02
STATUS = EXACT_B_TIER
```

For every smooth `iota : CP1 -> P_ADM`, exactness and Stokes give

```text
integral_CP1 iota*Omega_ADM = 0.
```

Since `integral_CP1 hbar omega_FS = 2 pi hbar`, no global equality
`iota*Omega_ADM=hbar omega_FS` exists for `hbar>0`.

The obstruction applies to the unreduced exact cotangent phase space. A
symplectic quotient or boundary/edge sector may evade it.
