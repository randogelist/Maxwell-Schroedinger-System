# derivation_of_ACTION_CELL_MATCHING_EQUIVALENCE

```text
ENDPOINT_ID = QMGR-11
STATUS = EXACT_B_TIER
```

With `integral omega_FS = 2 pi`, define

```text
A_Q  = (1/(2 pi)) integral Omega_MS
A_GR = (1/(2 pi)) integral iota^*Omega_GR.
```

If both forms are proportional to the same `omega_FS`, then

```text
iota^*Omega_GR = Omega_MS
iff A_GR = A_Q
iff S_{kappa,epsilon} = hbar
iff Xi_{kappa,epsilon} = 1.
```

This reduces the matching calculation to one symplectic area after proportionality is proved.
