# derivation_of_PHYSICAL_TORUS_SCALE

```text
ENDPOINT_ID = QMGR-13
STATUS = EXACT_B_TIER
```

For a physical torus of side length `L`:

```text
x_phys = L x_unit
Delta_unit = L^2 Delta_phys
epsilon_phys = L epsilon_unit.
```

Hence

```text
exp((epsilon_unit^2/4) Delta_unit)
= exp((epsilon_phys^2/4) Delta_phys).
```

The Planck endpoint is

```text
epsilon_phys = 2 l_P
iff epsilon_unit = 2 l_P/L.
```
